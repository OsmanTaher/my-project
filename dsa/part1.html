1.1 ما هي الخوارزمية؟

💡 التعريف الرسمي

الخوارزمية هي مجموعة محدودة من الخطوات المرتبة والمحددة بوضوح لحل مشكلة معينة. تأخذ مدخلات وتنتج مخرجات خلال عدد منتهٍ من الخطوات.

فكّر في الخوارزمية كوصفة طبخ — لديك مكوّنات (مدخلات)، وخطوات محددة (المعالجة)، وطبق جاهز في النهاية (مخرجات). الفرق أن الخوارزمية تحل مشاكل حسابية.

1.2 خصائص الخوارزمية الجيدة

✦
المحدودية (Finiteness): تنتهي بعد عدد محدود من الخطوات.
✦
الوضوح (Definiteness): كل خطوة محددة بدقة، لا غموض.
✦
الفعالية (Effectiveness): كل خطوة قابلة للتنفيذ فعلياً.
✦
المدخلات (Input): صفر أو أكثر من القيم المدخلة.
✦
المخرجات (Output): قيمة ناتجة واحدة على الأقل.
✦
العمومية (Generality): تحل نوع المشكلة، لا حالة واحدة.

CHAPTER 02 — COMPLEXITY ANALYSIS
تعقيد الوقت والمساحة
Big-O Notation
قبل أن تكتب سطراً واحداً من كودك، لازم تعرف كيف تقيس كفاءته. Big-O هي لغة التواصل بين المبرمجين لوصف أداء الخوارزميات.

2.1 ما هو Big-O؟

💡 التعريف

Big-O Notation هو تدوين رياضي يصف كيف يتزايد وقت تنفيذ الخوارزمية أو استهلاكها للذاكرة مع زيادة حجم المدخلات (n). نركز على السلوك عند n الكبيرة ونتجاهل الثوابت.

2.2 ترتيب التعقيدات (من الأسرع للأبطأ)

O(1) → O(log n) → O(n) → O(n log n) → O(n²) → O(2ⁿ) → O(n!)
التعقيد الاسم n=10 n=100 n=1,000 n=10,000 مثال
O(1) ثابت 1 1 1 1 arr[i]
O(log n) لوغاريتمي 3 7 10 13 Binary Search
O(n) خطي 10 100 1K 10K Linear Search
O(n log n) شبه خطي 33 664 10K 133K Merge Sort
O(n²) تربيعي 100 10K 1M 100M Bubble Sort
O(2ⁿ) أسي 1,024 ∞ ∞ ∞ Fibonacci Naive
O(n!) عاملي 3.6M ∞ ∞ ∞ Permutations

2.3 قواعد حساب Big-O

1
تجاهل الثوابت
O(3n) = O(n) | O(100) = O(1) | O(5n²) = O(n²)
2
احتفظ بالحد الأعلى فقط (Dominant Term)
O(n² + n) = O(n²) | O(n log n + n) = O(n log n)
3
الحلقات المتداخلة تُضرب
حلقة O(n) بداخل حلقة O(n) = O(n²)
4
الحلقات المتتالية تُجمع
O(n) + O(m) = O(n + m) | لكن إن كانت نفس المتغير: O(n) + O(n) = O(n)

2.4 أمثلة عملية بـ C++

C++ — أمثلة Big-Ocomplexity_examples.cpp 
// ── O(1) — الوصول المباشر ──────────────────────
int getFirst(vector<int>& arr) {
    return arr[0];  // دائماً خطوة واحدة بغض النظر عن n
}

// ── O(n) — حلقة بسيطة ─────────────────────────
int findMax(vector<int>& arr) {
    int maxVal = arr[0];
    for (int x : arr)          // n تكرار
        maxVal = max(maxVal, x);
    return maxVal;
}

// ── O(n²) — حلقتان متداخلتان ──────────────────
bool hasDuplicate(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n; i++)       // n تكرار
        for (int j = i+1; j < n; j++)  // n تكرار
            if (arr[i] == arr[j]) return true;
    return false;
}

// ── O(log n) — النصف في كل مرة ────────────────
int binarySearch(vector<int>& arr, int target) {
    int l = 0, r = arr.size() - 1;
    while (l <= r) {              // log n تكرار فقط
        int mid = l + (r - l) / 2;
        if (arr[mid] == target) return mid;
        else if (arr[mid] < target) l = mid + 1;
        else r = mid - 1;
    }
    return -1;
}

2.5 تعقيد المساحة — Space Complexity

💾 تعقيد المساحة

كمية الذاكرة الإضافية التي تحتاجها الخوارزمية. O(1) = لا ذاكرة إضافية. O(n) = ذاكرة بحجم المدخلات.

✦
O(1): Bubble Sort — يعمل في مكانه
✦
O(n): Merge Sort — مصفوفة مساعدة
✦
O(n): Recursion — Call Stack
✦
O(log n): Binary Search (recursive)
🎯 أسئلة مقابلات شائعة — Big-O
ما تعقيد: for(i=0;i<n;i++) for(j=i;j<n;j++) ؟ — الجواب: O(n²) لأن مجموع التكرارات = n(n+1)/2 ≈ n²/2
هل O(2n) = O(n)؟ — نعم، الثوابت تُتجاهل في Big-O تماماً
ما الفرق بين Best/Average/Worst Case؟ — نأخذ Worst Case للضمان، Average للواقع العملي
📝 تمرين — حدد التعقيدEasy
C++ — ما تعقيد كل دالة؟ 
// (أ) ما تعقيد هذه الدالة؟
void foo(int n) {
    for (int i = 1; i <= n; i *= 2)
        cout << i;
}

// (ب) ما تعقيد هذه الدالة؟
void bar(int n) {
    for (int i = 0; i < n; i++)
        for (int j = 0; j < 100; j++)
            cout << i + j;
}

// (ج) ما تعقيد هذه الدالة؟
void baz(int n) {
    for (int i = 0; i < n; i++)
        cout << i;
    for (int j = 0; j < n*n; j++)
        cout << j;
}

الإجابات:
(أ) O(log n) — i يتضاعف في كل مرة (1,2,4,8...) → log₂n تكرار
(ب) O(n) — الحلقة الداخلية ثابتة (100 مرة دائماً) → تُتجاهل
(ج) O(n²) — الحلقة الثانية O(n²) تسود على O(n) الأولى

3.1 ما هي المصفوفة؟

💡 التعريف

المصفوفة هي مجموعة من العناصر من نفس النوع مخزّنة في مواقع ذاكرة متجاورة. يُحدد كل عنصر بفهرسه (index) الذي يبدأ من صفر.

📍في الذاكرة، العناصر متجاورة تماماً. لو arr[0] في العنوان 1000، فـ arr[1] في 1004 (لكل int 4 bytes). هذا ما يجعل الوصول O(1).

3.2 عمليات المصفوفة بـ C++

C++arrays_basics.cpp 
#include <iostream>
#include <vector>
using namespace std;

int main() {
    // ── إنشاء مصفوفة ──────────────────────────────
    int arr[5] = {10, 20, 30, 40, 50};   // ثابتة الحجم
    vector<int> v = {10, 20, 30};        // ديناميكية
    vector<int> v2(5, 0);               // 5 عناصر قيمتها 0

    // ── الوصول O(1) ───────────────────────────────
    cout << arr[2];           // 30
    cout << v.front();        // 10 — أول عنصر
    cout << v.back();         // 30 — آخر عنصر
    cout << v.size();         // 3

    // ── الإضافة ───────────────────────────────────
    v.push_back(40);         // O(1) amortized — للنهاية
    v.insert(v.begin(), 5);  // O(n) — للبداية (إزاحة)
    v.insert(v.begin()+2, 15); // O(n) — للوسط

    // ── الحذف ─────────────────────────────────────
    v.pop_back();             // O(1) — من النهاية
    v.erase(v.begin());      // O(n) — من البداية
    v.clear();               // O(n) — حذف الكل

    // ── الاستعراض ─────────────────────────────────
    for (int i = 0; i < v.size(); i++)
        cout << v[i] << " ";

    for (int x : v) cout << x << " "; // Range-based
}
العملية التعقيد الزمني التعقيد المكاني ملاحظة
الوصول arr[i] O(1) O(1) العنوان = base + i×size
البحث (unsorted) O(n) O(1) Linear Scan
البحث (sorted) O(log n) O(1) Binary Search
push_back O(1)* O(1) *amortized مع vector
insert (beginning/middle) O(n) O(1) إزاحة العناصر
pop_back O(1) O(1) —
erase (beginning/middle) O(n) O(1) إزاحة العناصر

3.3 تمارين LeetCode Style

مسألة 1: Two SumEasy GoogleAmazonMetaApple

المشكلة: أعطيت مصفوفة nums وعدد target، أرجع فهارس العنصرين اللذين مجموعهما يساوي target.

مثال: nums = [2,7,11,15], target = 9 → Output: [0,1] لأن 2+7=9

💭فكّر أولاً: الحل Brute Force بحلقتين O(n²). لكن كيف نوصل لـ O(n) باستخدام Hash Map؟ الفكرة: لكل رقم، ابحث عن "complement = target - رقم" في الـ map.
C++ — الحل الأمثل O(n) / Space O(n) 
vector<int> twoSum(vector<int>& nums, int target) {
    unordered_map<int, int> seen; // value → index

    for (int i = 0; i < nums.size(); i++) {
        int complement = target - nums[i];

        if (seen.count(complement))
            return {seen[complement], i}; // وجدناه!

        seen[nums[i]] = i; // خزّن لاحقاً
    }
    return {}; // لا حل
}
مسألة 2: Maximum Subarray (Kadane's Algorithm)Medium MicrosoftAppleAmazon

المشكلة: أوجد المصفوفة الجزئية المتجاورة ذات المجموع الأعلى.

مثال: [-2,1,-3,4,-1,2,1,-5,4] → 6 (المصفوفة [4,-1,2,1])

C++ — Kadane's Algorithm O(n) / Space O(1) 
int maxSubArray(vector<int>& nums) {
    int maxSum = nums[0];
    int curSum = nums[0];

    for (int i = 1; i < nums.size(); i++) {
        // هل أبدأ من الصفر أم أكمل التسلسل؟
        curSum = max(nums[i], curSum + nums[i]);
        maxSum = max(maxSum, curSum);
    }
    return maxSum;
}
// الفكرة: إذا curSum أصبح سالباً، ابدأ من جديد
مسألة 3: Product of Array Except SelfMedium MetaAmazonGoogle

المشكلة: أرجع مصفوفة بحيث output[i] = حاصل ضرب كل العناصر عدا nums[i]. بدون استخدام القسمة!

مثال: [1,2,3,4] → [24,12,8,6]

C++ — Prefix & Suffix Products O(n) / Space O(1) 
vector<int> productExceptSelf(vector<int>& nums) {
    int n = nums.size();
    vector<int> res(n, 1);

    // مرور أول: ضرب ما على اليمين (prefix)
    int prefix = 1;
    for (int i = 0; i < n; i++) {
        res[i] = prefix;
        prefix *= nums[i];
    }

    // مرور ثانٍ: ضرب ما على اليسار (suffix)
    int suffix = 1;
    for (int i = n-1; i >= 0; i--) {
        res[i] *= suffix;
        suffix *= nums[i];
    }
    return res;
}

CHAPTER 04 — LINKED LISTS
القائمة المرتبطة
Linked Lists
بخلاف المصفوفة، القائمة المرتبطة تتيح إدراجًا وحذفًا بـ O(1) من أي مكان — لكن لها ثمن. فهمها صح = فهم نصف هياكل البيانات.

4.1 ما هي القائمة المرتبطة؟

القائمة المرتبطة هي سلسلة من العقد (Nodes)، كل عقدة تحتوي على البيانات + مؤشر للعقدة التالية. العقد ليست متجاورة في الذاكرة.

4.2 تنفيذ Singly Linked List بـ C++

C++linked_list.cpp 
// ── تعريف العقدة ──────────────────────────────
struct Node {
    int data;
    Node* next;
    Node(int val) : data(val), next(nullptr) {}
};

class LinkedList {
public:
    Node* head = nullptr;

    // إضافة في البداية O(1)
    void prepend(int val) {
        Node* newNode = new Node(val);
        newNode->next = head;
        head = newNode;
    }

    // إضافة في النهاية O(n)
    void append(int val) {
        Node* newNode = new Node(val);
        if (!head) { head = newNode; return; }
        Node* cur = head;
        while (cur->next) cur = cur->next;
        cur->next = newNode;
    }

    // حذف قيمة O(n)
    void deleteVal(int val) {
        if (!head) return;
        if (head->data == val) { head = head->next; return; }
        Node* cur = head;
        while (cur->next && cur->next->data != val)
            cur = cur->next;
        if (cur->next) cur->next = cur->next->next;
    }

    // طباعة O(n)
    void print() {
        for (Node* cur = head; cur; cur = cur->next)
            cout << cur->data << " → ";
        cout << "NULL\n";
    }
};

4.3 مقارنة Array vs Linked List

العملية Array Linked List الأفضل لـ
الوصول بالفهرس O(1) O(n) Array ✅
البحث O(n) O(n) متساويان
الإدراج في البداية O(n) O(1) Linked List ✅
الإدراج في النهاية O(1)* O(n) Array ✅
الحذف من البداية O(n) O(1) Linked List ✅
استخدام الذاكرة متجاور (Cache-friendly) مبعثر (Pointers overhead) Array ✅

4.4 تمارين LeetCode Style

مسألة 1: Reverse Linked ListEasy AmazonMicrosoftAppleMeta

المشكلة: اعكس قائمة مرتبطة. 1→2→3→4→5 تصبح 5→4→3→2→1

C++ — Iterative: O(n) / Space O(1) 
Node* reverseList(Node* head) {
    Node* prev = nullptr;
    Node* curr = head;

    while (curr) {
        Node* nextNode = curr->next; // 1. احفظ التالي
        curr->next = prev;            // 2. اعكس الاتجاه
        prev = curr;                  // 3. تقدّم prev
        curr = nextNode;              // 4. تقدّم curr
    }
    return prev; // الجذر الجديد
}
مسألة 2: Detect Cycle — Floyd's AlgorithmMedium GoogleMetaAmazon

المشكلة: هل توجد دورة (cycle) في القائمة المرتبطة؟

💡خوارزمية فلويد — السلحفاة والأرنب: مؤشر Slow يتحرك خطوة، Fast يتحرك خطوتين. لو التقيا → توجد دورة!
C++ — Floyd's Cycle Detection: O(n) / Space O(1) 
bool hasCycle(Node* head) {
    Node* slow = head;
    Node* fast = head;

    while (fast && fast->next) {
        slow = slow->next;        // خطوة واحدة 🐢
        fast = fast->next->next;  // خطوتان 🐇
        if (slow == fast) return true; // التقيا!
    }
    return false; // fast وصل لـ NULL
}
// أفضل من HashSet: O(1) space بدلاً من O(n)
مسألة 3: Merge Two Sorted ListsEasy AmazonMicrosoftGoogle

المشكلة: ادمج قائمتين مرتبتين في قائمة واحدة مرتبة.

    if (!l1) return l2;
    if (!l2) return l1;

    if (l1->val <= l2->val) {
        l1->next = mergeTwoLists(l1->next, l2);
        return l1;
    } else {
        l2->next = mergeTwoLists(l1, l2->next);
        return l2;
    }
}

bool isValid(string s) {
    stack<char> st;
    unordered_map<char,char> match = {
        {')','('}, {']','['}, {'}','{'}
    };
    for (char c : s) {
        if (c=='(' || c=='[' || c=='{')
            st.push(c);
        else {
            if (st.empty() || st.top() != match[c])
                return false;
            st.pop();
        }
    }
    return st.empty();
}

💡الفكرة: Monotonic Stack — نخزّن الفهارس ذات الحرارة الأعلى. عندما نجد يوم أحر، نُحسب المسافة.
C++ — Monotonic Stack O(n) / Space O(n) 
vector<int> dailyTemperatures(vector<int>& t) {
    int n = t.size();
    vector<int> res(n, 0);
    stack<int> st; // فهارس

    for (int i = 0; i < n; i++) {
        while (!st.empty() && t[i] > t[st.top()]) {
            res[st.top()] = i - st.top();
            st.pop();
        }
        st.push(i);
    }
    return res;
}

int binarySearch(vector<int>& arr, int target) {
    int l = 0, r = arr.size() - 1;

    while (l <= r) {
        int mid = l + (r - l) / 2; // تجنب Integer Overflow!

        if      (arr[mid] == target) return mid;
        else if (arr[mid] <  target) l = mid + 1; // ابحث يميناً
        else                         r = mid - 1; // ابحث يساراً
    }
    return -1;
}
// Time: O(log n) | Space: O(1)

int search(vector<int>& arr, int target) {
    int l = 0, r = arr.size() - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (arr[mid] == target) return mid;

        if (arr[l] <= arr[mid]) { // النصف الأيسر مرتب
            if (arr[l] <= target && target < arr[mid])
                r = mid - 1; // ابحث يساراً
            else
                l = mid + 1; // ابحث يميناً
        } else {               // النصف الأيمن مرتب
            if (arr[mid] < target && target <= arr[r])
                l = mid + 1; // ابحث يميناً
            else
                r = mid - 1; // ابحث يساراً
        }
    }

}

void bubbleSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n-1; i++) {
        bool swapped = false;         // Optimization!
        for (int j = 0; j < n-i-1; j++) {
            if (arr[j] > arr[j+1]) {
                swap(arr[j], arr[j+1]);
                swapped = true;
            }
        }
        if (!swapped) break; // مرتبة بالفعل!
    }
}
// Time: O(n²) worst | O(n) best | Space: O(1)

7.2 Selection Sort

C++
void selectionSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n-1; i++) {
        int minIdx = i;
        for (int j = i+1; j < n; j++)
            if (arr[j] < arr[minIdx])
                minIdx = j;
        swap(arr[i], arr[minIdx]);
    }
}
// O(n²) always | Space: O(1)

7.3 Insertion Sort

C++
void insertionSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 1; i < n; i++) {
        int key = arr[i], j = i-1;
        while (j >= 0 && arr[j] > key) {
            arr[j+1] = arr[j]; j--;
        }
        arr[j+1] = key;
    }
}
// O(n²) worst | O(n) best

8.1 Merge Sort — فرز الدمج ⭐

C++merge_sort.cpp 
void merge(vector<int>& arr, int l, int m, int r) {
    vector<int> left(arr.begin()+l, arr.begin()+m+1);
    vector<int> right(arr.begin()+m+1, arr.begin()+r+1);
    int i = 0, j = 0, k = l;
    while (i < left.size() && j < right.size())
        arr[k++] = (left[i] <= right[j]) ? left[i++] : right[j++];
    while (i < left.size())  arr[k++] = left[i++];
    while (j < right.size()) arr[k++] = right[j++];
}

void mergeSort(vector<int>& arr, int l, int r) {
    if (l >= r) return;
    int m = l + (r - l) / 2;
    mergeSort(arr, l, m);
    mergeSort(arr, m+1, r);
    merge(arr, l, m, r);
}
// Time: O(n log n) always | Space: O(n)

8.2 Quick Sort — الفرز السريع ⭐⭐

C++quick_sort.cpp 
int partition(vector<int>& arr, int l, int r) {
    int pivot = arr[r], i = l - 1;
    for (int j = l; j < r; j++)
        if (arr[j] <= pivot)
            swap(arr[++i], arr[j]);
    swap(arr[i+1], arr[r]);
    return i + 1;
}

void quickSort(vector<int>& arr, int l, int r) {
    if (l < r) {
        int pi = partition(arr, l, r);
        quickSort(arr, l, pi - 1);
        quickSort(arr, pi + 1, r);
    }
}
// Time: O(n log n) avg | O(n²) worst | Space: O(log n)

struct TreeNode {
    int val;
    TreeNode *left, *right;
    TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
};

// ── الإدراج في BST O(log n) avg ───────────────
TreeNode* insert(TreeNode* root, int val) {
    if (!root) return new TreeNode(val);
    if      (val < root->val) root->left  = insert(root->left,  val);
    else if (val > root->val) root->right = insert(root->right, val);
    return root;
}

// ── البحث في BST O(log n) avg ─────────────────
bool search(TreeNode* root, int val) {
    if (!root) return false;
    if (root->val == val) return true;
    if (val < root->val) return search(root->left, val);
    return search(root->right, val);
}

// ── Inorder → ترتيب تصاعدي ───────────────────
void inorder(TreeNode* root) {
    if (!root) return;
    inorder(root->left);
    cout << root->val << " ";
    inorder(root->right);
}
