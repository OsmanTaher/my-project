CHAPTER 01 — INTRODUCTION TO C++
الهيكل الأساسي لبرنامج C++
Basic Anatomy & Hello World
لغة C++ هي لغة مترجمة (Compiled)، قوية جداً في التعامل المباشر مع الذاكرة، وتدعم البرمجة الإجرائية والكائنية (Multi-paradigm). تعتبر الخيار الأول في برمجة الألعاب، محركات البحث، والأنظمة المدمجة.

1.1 كود C++ الأول (Hello World)

💡 ملاحظة فنية

أي برنامج C++ يجب أن يحتوي على دالة رئيسية تُسمى main()، وهي نقطة البداية (Entry Point) لتنفيذ الكود.

C++ Code main.cpp 
// 1. استدعاء مكتبة الإدخال والإخراج القياسية
#include <iostream>

// 2. الدالة الرئيسية (نقطة بداية التنفيذ)
int main() {
    
    // 3. طباعة نص على الشاشة ثم النزول لسطر جديد
    std::cout << "Hello, C++ Developers!" << std::endl;
    
    // 4. إرجاع 0 لنظام التشغيل (دليل على نجاح التنفيذ)
    return 0;
}

1.2 تشريح الكود (Code Anatomy)

#include <iostream>

موجه للمعالج الأولي (Preprocessor Directive). يقوم بإدراج مكتبة input output stream التي تحتوي على أوامر الطباعة وإدخال البيانات.

int main() { ... }

الدالة الرئيسية. الكلمة int تعني أن الدالة سترجع رقماً صحيحاً (Integer) عند انتهائها.

std::cout << ...

أمر الطباعة. cout تعني Character Output. الرمز << هو عامل الإدراج (Insertion Operator). بادئة std:: تعني أننا نستخدم مساحة الأسماء القياسية (Standard Namespace).

return 0;

تُخبر نظام التشغيل أن البرنامج انتهى بدون أي أخطاء. (في حالة حدوث خطأ كارثي نعيد رقم غير الصفر).

1.3 الممارسة المتعارف عليها: using namespace std

في المشاريع التعليمية والصغيرة، يفضل المبرمجون استخدام using namespace std; لتجنب تكرار كتابة std::، لكن في المشاريع الاحترافية الكبيرة يُنصح بتجنبها لمنع تعارض الأسماء (Name Clashes).

C++ Code الممارسة المختصرة 
#include <iostream>
using namespace std; // إتاحة كل محتويات مكتبة std

int main() {
    cout << "No need for std:: anymore!" << endl;
    return 0;
}

CHAPTER 02 — VARIABLES, DATA TYPES & I/O
المتغيرات، أنواع البيانات،
والإدخال والإخراج
C++ هي لغة "قوية التنميط" (Strongly Typed)، مما يعني أن كل متغير يجب أن يُعرّف بنوع بيانات محدد مسبقاً قبل استخدامه. هذا يعطي المترجم (Compiler) القدرة على تحسين أداء الذاكرة واكتشاف الأخطاء مبكراً.

2.1 أنواع البيانات الأساسية (Primitive Types)

النوع (Type)الوصف (Description)الحجم بالذاكرة (عبر الأنظمة)مثال
intرقم صحيح (بدون كسور)4 Bytesint age = 25;
doubleرقم عشري مزدوج الدقة8 Bytesdouble price = 19.99;
floatرقم عشري عادي (يُفضل double)4 Bytesfloat pi = 3.14f;
charحرف واحد فقط (بين علامتي ' ')1 Bytechar grade = 'A';
boolقيمة منطقية (صواب/خطأ)1 Bytebool isPassed = true;
std::stringسلسلة نصية (نص كامل)حسب طول النصstring name = "Ali";

2.2 الإدخال والإخراج (cin & cout)

💡 نستخدم cout (مع الرمز <<) لطباعة البيانات على الشاشة، ونستخدم cin (مع الرمز >>) لاستقبال البيانات من المستخدم.
C++ Code io_example.cpp 
#include <iostream>
#include <string> // مكتبة النصوص

using namespace std;

int main() {
    // 1. تعريف المتغيرات
    string userName;
    int userAge;

    // 2. طلب إدخال الاسم
    cout << "Enter your name: ";
    cin >> userName; // استقبال كلمة واحدة

    // 3. طلب إدخال العمر
    cout << "Enter your age: ";
    cin >> userAge;

    // 4. طباعة النتيجة (دمج النصوص والمتغيرات)
    cout << "Welcome " << userName << ", you are " << userAge << " years old." << endl;

    return 0;
}

2.3 الثوابت (Constants)

إذا أردت حماية متغير من التعديل لاحقاً في الكود، استخدم الكلمة المفتاحية const.

const double PI = 3.14159;
// PI = 3.14; // ❌ Error: assignment of read-only variable

CHAPTER 03 — CONTROL FLOW
الشروط والحلقات التكرارية
Conditions & Loops
البرنامج لا يسير دائماً في خط مستقيم. باستخدام جمل الشرط (if/switch) والحلقات التكرارية (for/while)، نمنح البرنامج القدرة على اتخاذ القرارات وتكرار المهام بناءً على البيانات.

3.1 الجمل الشرطية (If / Else If / Else)

✨ هيكل If الأساسي

يتم تقييم الشرط الموجود بين القوسين (). إذا كان true يُنفذ الكود، وإلا ينتقل للشرط الذي يليه.

⚡ المعاملات المنطقية

== (يساوي) ، != (لا يساوي)
&& (و - AND) ، || (أو - OR)

C++ Code conditions.cpp 
int grade = 85;

if (grade >= 90) {
    cout << "Excellent!" << endl;
} 
else if (grade >= 75 && grade < 90) {
    // سيتم تنفيذ هذا البلوك لأن 85 أكبر من 75 وأقل من 90
    cout << "Very Good!" << endl;
} 
else {
    cout << "Needs Improvement." << endl;
}

3.2 الحلقات التكرارية (Loops)

تُستخدم لتكرار تنفيذ جزء من الكود عدة مرات دون الحاجة لكتابته مجدداً. لدينا 3 أنواع رئيسية في C++.

1
حلقة (For Loop)
تُستخدم عندما نكون نعرف مسبقاً عدد مرات التكرار المطلوبة.
for (initialization; condition; increment) { ... }
2
حلقة (While Loop)
تُستخدم عندما نكرر الكود بناءً على شرط معين (طالما الشرط متحقق). يتم فحص الشرط قبل الدخول للحلقة.
3
حلقة (Do-While Loop)
نفس فكرة While، ولكن يتم تنفيذ الكود مرة واحدة على الأقل قبل فحص الشرط.
C++ Code loops.cpp 
// 1. مثال For Loop (العد من 1 إلى 5)
for (int i = 1; i <= 5; i++) {
    cout << "Count: " << i << endl;
}

cout << "-------------------" << endl;

// 2. مثال While Loop (انتظار إدخال رقم موجب)
int number = -1;
while (number < 0) {
    cout << "Enter a positive number: ";
    cin >> number;
}
cout << "Thank you! You entered: " << number << endl;
⚠️ تحذير الـ Infinite Loop: في حلقات الـ while و for تأكد دائماً أن الشرط سيصل إلى نقطة الانتهاء (يصبح false)، وإلا سيعلق البرنامج في حلقة لانهائية ويتوقف عن الاستجابة.

CHAPTER 04 — FUNCTIONS & SCOPE
الدوال ونطاق المتغيرات
Functions & Variable Scope
الدوال (Functions) هي كتل من الأوامر البرمجية التي تؤدي مهمة محددة ويمكن إعادة استخدامها. هي التطبيق العملي الأول لمبدأ DRY (Don't Repeat Yourself) في البرمجة.

4.1 تشريح الدالة (Anatomy of a Function)

1️⃣ نوع الإرجاع (Return Type)

نوع البيانات الذي ستعيده الدالة (مثل int, double). إذا لم تكن ستعيد شيئاً نستخدم الكلمة void.

2️⃣ المعاملات (Parameters)

المدخلات التي تحتاجها الدالة لتعمل. توضع بين الأقواس (). يمكن أن تكون الدالة بدون معاملات.

C++ Code functions.cpp 
#include <iostream>
using namespace std;

// 1. دالة تعيد قيمة (تجمع رقمين)
int addNumbers(int a, int b) {
    int sum = a + b;
    return sum; // إرجاع النتيجة
}

// 2. دالة لا تعيد قيمة (Void Function)
void printGreeting(string name) {
    cout << "Hello, " << name << "!" << endl;
}

int main() {
    // استدعاء الدوال (Function Calls)
    int result = addNumbers(10, 5);
    cout << "Sum is: " << result << endl;

    printGreeting("Ali");
    
    return 0;
}

4.2 نطاق المتغيرات (Variable Scope)

المتغير المعرف داخل دالة يُسمى (Local Variable)، ولا يمكن استخدامه خارج هذه الدالة. بمجرد انتهاء الدالة، يتم مسح المتغير من الذاكرة.

CHAPTER 05 — POINTERS & REFERENCES
المؤشرات والمراجع
Pointers & References
القوة العظمى للغة C++ تكمن هنا. المؤشرات تسمح لك بالوصول المباشر إلى عناوين الذاكرة (RAM) والتحكم فيها، مما يوفر أداءً خارقاً عند استخدامه بشكل صحيح.

5.1 ما هو المؤشر (Pointer)؟

📍 المفهوم الأساسي

المؤشر هو متغير وظيفته الوحيدة هي تخزين عنوان الذاكرة لمتغير آخر. نستخدم الرمز & للحصول على العنوان، والرمز * لتعريف المؤشر أو قراءة قيمته.

C++ Code pointers.cpp 
int age = 25;
int* ptr = &age; // المؤشر يخزن عنوان الذاكرة الخاص بمتغير age

cout << age << endl;    // تطبع: 25
cout << ptr << endl;    // تطبع عنوان الذاكرة (مثل: 0x7ffe102a...)
cout << *ptr << endl;   // تطبع القيمة الموجودة داخل العنوان: 25 (Dereferencing)

*ptr = 30;              // تعديل القيمة من خلال المؤشر
cout << age << endl;    // تطبع: 30 (تغيرت لأن المؤشر عدل في الذاكرة مباشرة)

5.2 المراجع (References) وتمرير البيانات

المرجع (Reference) هو ببساطة اسم مستعار (Alias) لمتغير موجود. الفرق بينه وبين المؤشر أنه أسهل في الاستخدام (لا يحتاج *)، ولا يمكن تغييره ليشير لمتغير آخر بعد تعريفه.

❌ Pass by Value

يتم أخذ نسخة كاملة من البيانات في الذاكرة. بطيء جداً مع البيانات الكبيرة كالنصوص.

✅ Pass by Reference

نمرر عنوان المتغير باستخدام &. سريع جداً ولا يستهلك ذاكرة إضافية.

🛡️ Pass by Const Ref

نمرر بالمرجعية للسرعة، ونضع const لمنع التعديل (أفضل ممارسة Best Practice).

C++ Code best_practices_ref.cpp 
#include <iostream>
using namespace std;

// استخدام المرجعية لتبديل قيمتين في الذاكرة مباشرة
void swapNumbers(int& a, int& b) {
    int temp = a;
    a = b;
    b = temp;
}

// الممارسة الأفضل: تمرير النصوص الكبيرة كـ Const Reference
void printLargeData(const string& data) {
    cout << data << endl;
    // data = "new"; // ❌ خطأ برمجي: Const تمنع التعديل
}

int main() {
    int x = 10, y = 20;
    swapNumbers(x, y);
    cout << "x=" << x << " y=" << y << endl; // النتيجة: x=20 y=10

    string hugeText = "Huge data...";
    printLargeData(hugeText);
    
    return 0;
}
💡 قاعدة المبرمج المحترف: إذا كان حجم المتغير أكبر من المؤشر (أكبر من 8 Bytes مثل الـ `string` أو الـ `classes`)، قم بتمريره دائماً بالمرجعية `const type&` لتحسين الأداء.

CHAPTER 06 — OBJECT-ORIENTED PROGRAMMING
البرمجة الكائنية (OOP)
Classes, Objects & Inheritance
البرمجة الكائنية هي نموذج برمجي يعتمد على تمثيل الأشياء الحقيقية كـ "كائنات" (Objects) تمتلك خصائص (Attributes) وسلوكيات (Methods). هذا النموذج يسهل صيانة الكود وتطوير الأنظمة المعقدة.

6.1 الفئات (Classes) والكائنات (Objects)

📐 المفهوم الأساسي

الـ Class (الفئة) هو المخطط الهندسي (Blueprint). بينما الـ Object (الكائن) هو النسخة الحقيقية المصنوعة من هذا المخطط.
مثال: "السيارة" هي Class، بينما "سيارتك التويوتا السوداء" هي Object.

🔒 محددات الوصول (Access Specifiers)
✦
private: لا يمكن الوصول إليها إلا من داخل الكلاس (الوضع الافتراضي).
✦
public: يمكن الوصول إليها من أي مكان في البرنامج.
✦
protected: مثل private لكن يمكن للـ Classes الوارثة الوصول إليها.
🏗️ الباني (Constructor)

دالة خاصة تحمل نفس اسم الـ Class ولا تُرجع قيمة. تُستدعى تلقائياً مرة واحدة فقط عند إنشاء الكائن (Object) لتهيئة المتغيرات الأولية.

6.2 مثال عملي: التغليف (Encapsulation)

💡 Best Practice: اجعل جميع المتغيرات (Attributes) من النوع private لحمايتها، ووفر دوال public (Getters & Setters) للتعامل معها. هذا هو جوهر مبدأ "التغليف".
C++ Code BankAccount.cpp 
#include <iostream>
using namespace std;

class BankAccount {
private:
    // المتغيرات محمية لا يمكن تعديلها من الخارج مباشرة
    string ownerName;
    double balance;

public:
    // Constructor: يُهيئ الحساب عند إنشائه
    BankAccount(string name, double initialBalance) {
        ownerName = name;
        balance = initialBalance;
    }

    // Setter: طريقة آمنة لإيداع المال
    void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }

    // Getter: لقراءة الرصيد فقط دون تعديله
    double getBalance() const { 
        return balance; 
    }
};

int main() {
    // إنشاء كائن (Object) من الفئة BankAccount
    BankAccount myAccount("Ezzeldin", 1000.0);

    myAccount.deposit(500.0); // إيداع آمن عبر الدالة
    cout << "Balance: $" << myAccount.getBalance() << endl;
    
    // myAccount.balance = 5000; // ❌ خطأ برمجي: balance هو private

    return 0;
}

6.3 الوراثة (Inheritance) وتعدد الأشكال (Polymorphism)

الوراثة تسمح لك بإنشاء فئة جديدة (Derived Class) تأخذ كل خصائص فئة موجودة (Base Class) وتضيف عليها. هذا يقلل تكرار الكود بشكل هائل.

C++ Code inheritance.cpp 
// الفئة الأساسية (الأب)
class Animal {
public:
    string name;
    
    Animal(string n) { name = n; }
    
    // كلمة virtual تسمح للفئات الأبناء بإعادة كتابة الدالة (Overriding)
    virtual void makeSound() const {
        cout << "Some generic animal sound" << endl;
    }
};

// الفئة المشتقة (الابن) ترث من Animal
class Dog : public Animal {
public:
    // استدعاء باني الأب
    Dog(string n) : Animal(n) {}

    // إعادة تعريف السلوك (Polymorphism)
    void makeSound() const override {
        cout << name << " says: Woof! Woof!" << endl;
    }
};

int main() {
    Dog myDog("Rex");
    myDog.makeSound(); // النتيجة: Rex says: Woof! Woof!
    
    return 0;
}
⚠️ تحذير الذاكرة: إذا استخدمت virtual functions في كلاس، يجب دائماً أن تجعل الـ Destructor (الهادم) من النوع virtual لتجنب تسرب الذاكرة (Memory Leaks) عند حذف الكائنات المشتقة.

CHAPTER 04 — FUNCTIONS & SCOPE
الدوال ونطاق المتغيرات
Functions & Variable Scope
الدوال (Functions) هي كتل من الأوامر البرمجية التي تؤدي مهمة محددة ويمكن إعادة استخدامها. هي التطبيق العملي الأول لمبدأ DRY (Don't Repeat Yourself) في البرمجة.

4.1 تشريح الدالة (Anatomy of a Function)

1️⃣ نوع الإرجاع (Return Type)

نوع البيانات الذي ستعيده الدالة (مثل int, double). إذا لم تكن ستعيد شيئاً نستخدم الكلمة void.

2️⃣ المعاملات (Parameters)

المدخلات التي تحتاجها الدالة لتعمل. توضع بين الأقواس (). يمكن أن تكون الدالة بدون معاملات.

C++ Code functions.cpp 
#include <iostream>
using namespace std;

// 1. دالة تعيد قيمة (تجمع رقمين)
int addNumbers(int a, int b) {
    int sum = a + b;
    return sum; // إرجاع النتيجة
}

// 2. دالة لا تعيد قيمة (Void Function)
void printGreeting(string name) {
    cout << "Hello, " << name << "!" << endl;
}

int main() {
    // استدعاء الدوال (Function Calls)
    int result = addNumbers(10, 5);
    cout << "Sum is: " << result << endl;

    printGreeting("Ali");
    
    return 0;
}

4.2 نطاق المتغيرات (Variable Scope)

المتغير المعرف داخل دالة يُسمى (Local Variable)، ولا يمكن استخدامه خارج هذه الدالة. بمجرد انتهاء الدالة، يتم مسح المتغير من الذاكرة.

CHAPTER 05 — POINTERS & REFERENCES
المؤشرات والمراجع
Pointers & References
القوة العظمى للغة C++ تكمن هنا. المؤشرات تسمح لك بالوصول المباشر إلى عناوين الذاكرة (RAM) والتحكم فيها، مما يوفر أداءً خارقاً عند استخدامه بشكل صحيح.

5.1 ما هو المؤشر (Pointer)؟

📍 المفهوم الأساسي

المؤشر هو متغير وظيفته الوحيدة هي تخزين عنوان الذاكرة لمتغير آخر. نستخدم الرمز & للحصول على العنوان، والرمز * لتعريف المؤشر أو قراءة قيمته.

C++ Code pointers.cpp 
int age = 25;
int* ptr = &age; // المؤشر يخزن عنوان الذاكرة الخاص بمتغير age

cout << age << endl;    // تطبع: 25
cout << ptr << endl;    // تطبع عنوان الذاكرة (مثل: 0x7ffe102a...)
cout << *ptr << endl;   // تطبع القيمة الموجودة داخل العنوان: 25 (Dereferencing)

*ptr = 30;              // تعديل القيمة من خلال المؤشر
cout << age << endl;    // تطبع: 30 (تغيرت لأن المؤشر عدل في الذاكرة مباشرة)

5.2 المراجع (References) وتمرير البيانات

المرجع (Reference) هو ببساطة اسم مستعار (Alias) لمتغير موجود. الفرق بينه وبين المؤشر أنه أسهل في الاستخدام (لا يحتاج *)، ولا يمكن تغييره ليشير لمتغير آخر بعد تعريفه.

❌ Pass by Value

يتم أخذ نسخة كاملة من البيانات في الذاكرة. بطيء جداً مع البيانات الكبيرة كالنصوص.

✅ Pass by Reference

نمرر عنوان المتغير باستخدام &. سريع جداً ولا يستهلك ذاكرة إضافية.

🛡️ Pass by Const Ref

نمرر بالمرجعية للسرعة، ونضع const لمنع التعديل (أفضل ممارسة Best Practice).

C++ Code best_practices_ref.cpp 
#include <iostream>
using namespace std;

// استخدام المرجعية لتبديل قيمتين في الذاكرة مباشرة
void swapNumbers(int& a, int& b) {
    int temp = a;
    a = b;
    b = temp;
}

// الممارسة الأفضل: تمرير النصوص الكبيرة كـ Const Reference
void printLargeData(const string& data) {
    cout << data << endl;
    // data = "new"; // ❌ خطأ برمجي: Const تمنع التعديل
}

int main() {
    int x = 10, y = 20;
    swapNumbers(x, y);
    cout << "x=" << x << " y=" << y << endl; // النتيجة: x=20 y=10

    string hugeText = "Huge data...";
    printLargeData(hugeText);
    
    return 0;
}
💡 قاعدة المبرمج المحترف: إذا كان حجم المتغير أكبر من المؤشر (أكبر من 8 Bytes مثل الـ `string` أو الـ `classes`)، قم بتمريره دائماً بالمرجعية `const type&` لتحسين الأداء.

CHAPTER 06 — OBJECT-ORIENTED PROGRAMMING
البرمجة الكائنية (OOP)
Classes, Objects & Inheritance
البرمجة الكائنية هي نموذج برمجي يعتمد على تمثيل الأشياء الحقيقية كـ "كائنات" (Objects) تمتلك خصائص (Attributes) وسلوكيات (Methods). هذا النموذج يسهل صيانة الكود وتطوير الأنظمة المعقدة.

6.1 الفئات (Classes) والكائنات (Objects)

📐 المفهوم الأساسي

الـ Class (الفئة) هو المخطط الهندسي (Blueprint). بينما الـ Object (الكائن) هو النسخة الحقيقية المصنوعة من هذا المخطط.
مثال: "السيارة" هي Class، بينما "سيارتك التويوتا السوداء" هي Object.

🔒 محددات الوصول (Access Specifiers)
✦
private: لا يمكن الوصول إليها إلا من داخل الكلاس (الوضع الافتراضي).
✦
public: يمكن الوصول إليها من أي مكان في البرنامج.
✦
protected: مثل private لكن يمكن للـ Classes الوارثة الوصول إليها.

STL: Vectors & Strings
الـ STL هي الكنز الحقيقي لمبرمجي C++. توفر هياكل بيانات (Containers) وخوارزميات جاهزة ومحسنة للأداء، مما يغنيك عن "إعادة اختراع العجلة" وإدارة الذاكرة يدوياً بالطرق القديمة.

7.1 المصفوفات الديناميكية (std::vector)

❌ المصفوفات القديمة (C-Arrays)

حجمها ثابت لا يتغير بعد الإنشاء، وتمريرها للدوال معقد، ولا تحمي من أخطاء تجاوز الحدود (Buffer Overflow).

✅ الـ Vector (C++ الحديثة)

مصفوفة ديناميكية تتمدد وتتقلص تلقائياً. تدير الذاكرة بنفسها، وتأتي مع دوال جاهزة لمعرفة الحجم وإضافة/حذف العناصر.

C++ Code vectors.cpp 
#include <iostream>
#include <vector> // استدعاء مكتبة الفيكتور
using namespace std;

int main() {
    // 1. تعريف Vector من الأرقام الصحيحة
    vector<int> numbers = {10, 20, 30};

    // 2. إضافة عناصر جديدة في النهاية (ديناميكياً)
    numbers.push_back(40);
    numbers.push_back(50);

    cout << "Size: " << numbers.size() << endl; // النتيجة: 5

    // 3. الممارسة الأفضل (Best Practice) للدوران على العناصر
    // استخدام Range-based for loop مع المرجعية الثابتة (const reference) لمنع النسخ البطيء
    cout << "Elements: ";
    for (const auto& num : numbers) {
        cout << num << " ";
    }
    cout << endl;

    return 0;
}

7.2 التعامل الآمن مع النصوص (std::string)

انسَ أمر الـ char arrays المعقدة في لغة C. فئة std::string في C++ هي كائن (Object) يدير ذاكرة النص تلقائياً ويوفر طرقاً سهلة للدمج، البحث، والقص.

C++ Code strings.cpp 
#include <iostream>
#include <string>
using namespace std;

int main() {
    string firstName = "Ezzeldin";
    string lastName = "Muhammed";

    // 1. الدمج المباشر بـ (+) بدلاً من دوال strcat القديمة
    string fullName = firstName + " " + lastName;
    
    cout << "Name: " << fullName << endl;
    cout << "Length: " << fullName.length() << " chars" << endl;

    // 2. الحصول على جزء من النص (Substring)
    // اقتطاع 8 حروف ابتداءً من الدليل (Index) رقم 0
    string firstOnly = fullName.substr(0, 8); 
    cout << "First Name extracted: " << firstOnly << endl;

    return 0;
}
🎯 قاعدة ذهبية في Modern C++: استخدم دائماً std::vector للمصفوفات، و std::string للنصوص. لا تلجأ للـ Raw Arrays أو المؤشرات التقليدية *char إلا إذا كنت تبرمج أنظمة مدمجة (Embedded) بذاكرة محدودة جداً وتعرف تماماً ما تفعله.
