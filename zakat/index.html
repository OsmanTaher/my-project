الخطوة 1: حساب النصاب الشرعي

النصاب الشرعي لوجوب الزكاة هو قيمة 85 جراماً من الذهب الصافي (عيار 24).

حد النصاب = 85 جرام × 0 = 0 SAR

الخطوة 2: تحويل وتقييم الذهب زكوياً

تتم زكاة الذهب بتحويل العيار المدخل إلى معيار الذهب النقي (عيار 24) بواسطة المعادلة الشرعية المعتمدة:

الوزن عيار 24 = (0 جرام × 0) ÷ 24 = 0 جرام نقي

وبالتالي تكون القيمة السوقية للذهب الخاضع للزكاة:

قيمة الذهب المالي = 0 جرام × 0 = 0 SAR

الخطوة 3: دمج الأصول ومقارنتها بالنصاب

نقوم بجمع النقد السائل والمدخرات مع القيمة المالية للذهب للتحقق من بلوغ النصاب:

مجموع الأصول = 0 (نقد) + 0 (ذهب) = 0 SAR

الخطوة 4: حساب مقدار الزكاة الواجبة

إذا بلغت أصولك الزكوية النصاب، يتم احتساب زكاة المال بنسبة 2.5% (أو ربع العشر أي بالقسمة على 40):

مقدار زكاتك = 0 × 0.025 = 0 SAR
