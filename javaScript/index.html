المتغيرات وإدارة الذاكرة
Memory allocation in JavaScript
الفهم الحقيقي لـ JavaScript يبدأ بالوعي بآلية تخزين البيانات. جافا سكريبت لا تخزن كل البيانات بنفس الطريقة، وفهمك للـ Stack والـ Heap سيوفر عليك ساعات طويلة من البحث عن ثغرات نسْخ الكائنات.

1.1 المتغيرات: let مقابل const و var

تطور الإعلان عن المتغيرات عبر الأجيال؛ من النطاق الوظيفي العشوائي لـ var إلى النطاق الكتلي المنضبط (Block Scope) للـ let والـ const في ES6.

🟢 let (محدودة النطاق)
▸
يمكن تعديل قيمتها لاحقاً في الكود.
▸
تتبع نطاق البلوك {} ولا تتسرب خارجه.
🟡 const (الثوابت)
▸
لا يمكن إعادة تعيين قيمتها مباشرة.
▸
تخضع لنطاق البلوك وتحمي المرجع (Reference) من التغيير.

1.2 أنواع البيانات وأين يتم تخزينها؟

💡 الفرق الجوهري في الذاكرة

الأنواع الأساسية (Primitive Types) مثل الأرقام والنصوص والقيم البولينية يتم تخزينها في الـ Stack Memory لسرعة الوصول إليها وتوفرها على قيم ثابتة الحجم. أما الأنواع المرجعية (Reference Types) مثل الكائنات والمصفوفات والدوال فيتم تخزين قيمها في الـ Heap Memory، بينما يخزن الـ Stack مؤشراً Pointer يدل على موقعها في الـ Heap.

JAVASCRIPT MEMORY ALLOCATION (STACK VS HEAP)
JavaScript Code Primitives vs Reference Types 
let age = 26; // يتم حفظ القيمة مباشرة في الـ Stack
let newAge = age; // يتم نسخ القيمة مباشرة
newAge = 27; // تعديلها لا يؤثر على age الأصلي

const user = { name: "Osman" }; // يحفظ العنوان في الـ Stack، والكائن في الـ Heap
const admin = user; // يتم نسخ العنوان فقط! يشير كلاهما لنفس الكائن
admin.name = "Ali"; 

console.log(user.name); // Output: "Ali" (تأثر الكائن الأصلي لتشاركهما المرجع!)

التحكم بمسار الكود وكيفية معالجة الحالات المنطقية المعقدة بذكاء، مع استعراض شامل للفرق بين مقارنات القيمة والنوع ومختلف أنواع الحلقات البرمجية.

2.1 العمليات ومقارنات التساوي (== vs ===)

الوقوع في فخ التساوي السطحي == أمر شائع جداً بجافا سكريبت بسبب التحويل التلقائي للأنواع (Type Coercion).

العملية الاسم السلوك والتحويل مثال
== التحقق السطحي يحاول تحويل النوعين ليصبحا متشابهين قبل المقارنة "5" == 5 // true
=== التحقق الدقيق يقارن القيمة والنوع معاً (الأكثر أماناً وموصى به دائماً) "5" === 5 // false
?? Nullish Coalescing يرجع القيمة اليمنى فقط إذا كانت اليسرى null أو undefined null ?? "default" // "default"

2.2 الجمل الشرطية الحديثة

بدلاً من بناء جدار من جمل if-else المتراكمة، نفضل تصفية الحالات باستخدام الـ Guard Clauses أو اللجوء للعمليات الثلاثية المختصرة.

JavaScript Clean Conditional Logic 
// الطريقة غير المنظمة باستخدام if-else المتداخلة
if (user) {
  if (user.isVerified) {
    grantAccess();
  } else {
    showVerificationError();
  }
}

// الطريقة الحديثة والاحترافية: استخدام الـ Guard Clauses
if (!user) return showError("المستخدم غير موجود");
if (!user.isVerified) return showVerificationError();

grantAccess(); // الكود يتدفق بسلاسة بدون تداخل عميق

2.3 الحلقات التكرارية (Loops) والفرق بين For-in و For-of

🔄 for...of Loop

تُستخدم للمرور على قيم (Values) كائنات قابلة للتكرار مثل المصفوفات والنصوص.

for (let val of [10, 20]) { console.log(val); } // 10, 20
🔑 for...in Loop

تُستخدم للمرور على مفاتيح/خصائص (Keys/Properties) الكائنات (Objects).

for (let key in {a: 1}) { console.log(key); } // "a"

CHAPTER 03 — FUNCTIONS MASTERCLASS
الدوال ومفهوم الرفع والـ Arrow Functions
Function expressions vs declarations
الدوال في جافا سكريبت هي "كائنات من الدرجة الأولى" (First-Class Citizens). سنتعلم كيف تؤثر آلية تعريف الدالة على تصرفها في محيط العمل البرمجي وعلاقتها بالكلمة المحجوزة this.

3.1 أنواع تعريف الدوال والـ Hoisting

هناك طريقتان أساسيتان لتعريف الدوال التقليدية، وتختلفان جذرياً في سلوك الرفع (Hoisting):

📣 Function Declaration

يتم رفعها بالكامل مع جسدها لأعلى نطاق التشغيل. يمكنك استدعاؤها قبل كتابتها في الكود بأي سطر.

function greet() { return "Hi!"; }
🎭 Function Expression

تُعامل كمعامل للمتغير. لا تُرفع، لذا ستحصل على خطأ ReferenceError إذا حاولت استدعاءها قبل تعريفها.

const greet = function() { return "Hi!"; }

3.2 الدوال السهمية (Arrow Functions) وحقيقة سياق This

💡 الـ Lexical this الخفي

الدوال السهمية () => {} ليست مجرد شكل مختصر للدوال؛ بل تتمتع بسلوك مميز جداً: لا تمتلك سياق This خاصاً بها. هي تلتقط قيمة الكلمة this من النطاق الخارجي الذي عُرفت فيه (Lexical Scope)، على عكس الدوال العادية التي تنشئ سياق this جديداً يعتمد على كيفية ونقطة استدعائها.

JavaScript Arrow vs Normal Function Shorthand & Scope 
const userCard = {
  username: "Osman",
  normalGreet: function() {
    setTimeout(function() {
      console.log("Normal:", this.username); // Output: undefined (setTimeout يغير سياق this إلى Window)
    }, 100);
  },
  arrowGreet: function() {
    setTimeout(() => {
      console.log("Arrow:", this.username); // Output: "Osman" (التقطت This من النطاق الخارجي للكارد)
    }, 100);
  }
};

userCard.normalGreet();
userCard.arrowGreet();

Arrays, Objects, Destructuring & Rest
التعامل الفعال مع هياكل البيانات والتحول نحو البرمجة الوظيفية عبر معالجة المصفوفات المتسلسلة وتفكيك العناصر بمرونة فائقة.

4.1 عمليات معالجة المصفوفات الكبرى (Pipeline)

بدلاً من استخدام الحلقات اليدوية، توفر جافا سكريبت دوال برمجية وظيفية راقية ومغلقة لتصفية وتحويل ودمج البيانات بشكل أنيق:

ARRAY PROCESSING PIPELINE
JavaScript Array Methods Chaining 
const numbers = [1, 2, 3, 4];

// معالجة البيانات بسلسلة واحدة نظيفة
const processed = numbers
  .filter(n => n % 2 === 0)  // [2, 4]
  .map(n => n * 2);         // [4, 8]

console.log(processed); // Output: [4, 8]

// دالة الاختزال لتجميع العناصر لعملية واحدة
const sum = processed.reduce((acc, curr) => acc + curr, 0);
console.log(sum); // Output: 12

4.2 التفكيك (Destructuring) ومكرر النشر (Spread/Rest)

يعتبر التفكيك أسرع وأسهل ميزة مستحدثة لاستخراج الخواص من الكائنات والمصفوفات بشكل مباشر ومقروء.

📦 Object Destructuring
const user = { name: "Osman", age: 26 };
const { name, age } = user;
console.log(name); // "Osman"
⚡ Rest & Spread Operators (...)
const arr1 = [1, 2];
const arr2 = [...arr1, 3, 4]; // Spread
const [first, ...rest] = arr2; // Rest

5.2 آلية تفاعل الأحداث (Bubbling vs Capturing)

⚙️ دورة حياة الحدث

عندما تضغط على زر داخل حاوية (Div)، لا يتأثر الزر فقط؛ بل ينتقل الحدث عبر 3 مراحل متتالية:
1. Capturing: يتجه الحدث لأسفل الشجرة من الـ Document حتى العنصر المستهدف.
2. Target: ينطلق الحدث عند العنصر الذي تم التفاعل معه (مثلاً الزر).
3. Bubbling: يعود الحدث للصعود لأعلى من العنصر المستهدف وصولاً للجذر (وهي الحالة الافتراضية لالتقاط الأحداث).

JavaScript DOM Manipulations & delegation 
// تحديد العناصر وتعديلها بأداء عالي
const ctaButton = document.querySelector("#main-btn");
ctaButton.textContent = "انقر للمتابعة ✨";
ctaButton.classList.add("bg-teal");

// استخدام تفويض الأحداث (Event Delegation) لتسريع الأداء
const listContainer = document.querySelector(".item-list");
listContainer.addEventListener("click", (event) => {
  // بدلاً من وضع مستمع لكل عنصر، نستمع للحاوية ونفلتر العنصر المنقور
  if (event.target.matches("li")) {
    console.log("تم نقر العنصر:", event.target.textContent);
    event.stopPropagation(); // إيقاف صعود الحدث (Prevent Bubbling) عند اللزوم
  }
});

6.2 إدارة جلب البيانات باستخدام Promises و Async / Await

الكتابة باستخدام async / await تقدم صياغة رائعة وسهلة القراءة تحول الأكواد المعقدة إلى شكل تتابعي متناسق ومريح للعين والذهن.

JavaScript Async API Fetch Modern Fetch & Error Handling 
// الطريقة الحديثة والمحبذة باستخدام async/await والتحقق من الأخطاء
async function fetchUserData(userId) {
  try {
    const response = await fetch(`https://api.aswanistack.com/users/${userId}`);
    
    // التحقق الفوري من حالة الاتصال (Guard Clause)
    if (!response.ok) {
      throw new Error(`خطأ في جلب البيانات: ${response.status}`);
    }

    const data = await response.json();
    return data;
  } catch (error) {
    console.error("حدث خلل أثناء الاتصال:", error.message);
    return null;
  }
}

// تجربة دمج البيانات غير المتزامنة
fetchUserData(101).then(user => console.log("المستخدم المتزامن:", user));

Scope, Execution Context & Closures
تحليل عميق لكيفية تخزين المحرك للمتغيرات داخل بيئات التشغيل، وشرح شامل ومبسط لأهم لغز ممتع في المقابلات التقنية: الـ Closures.

7.1 ما هو الـ Closure وكيف ينشأ؟

💡 التعريف الحاسم

الـ Closure هو قدرة الدالة الابنة على تذكر الوصول إلى نطاقها الخارجي (Lexical Scope) والبيانات المتواجدة فيه حتى بعد انتهاء تشغيل الدالة الأب وخروجها تماماً من الـ Call Stack.

JavaScript Scope Closure Encapsulation & Private State 
function createCounter() {
  let count = 0; // متغير خاص (Encapsulated/Private)

  return {
    increment: function() {
      count++;
      return count;
    },
    decrement: function() {
      count--;
      return count;
    }
  };
}

const myCounter = createCounter();
console.log(myCounter.increment()); // Output: 1
console.log(myCounter.increment()); // Output: 2 (يتذكر قيمة count السابقة!)
// لا توجد طريقة لتعديل المتغير count مباشرة من الخارج. هذا هو الأمان!

7.2 أساليب ربط سياق This يدوياً (call, apply, bind)

إذا واجهتك مشاكل في تفكك مرجع this، تتيح لك اللغة الربط اليدوي والتحكم الكامل في تحديد السياق:

📍 .call()

تستدعي الدالة فوراً مع تمرير الكائن كـ this وتمرير المعاملات مفصولة بفواصل.

func.call(obj, arg1, arg2);
📍 .apply()

تستدعي الدالة فوراً مع تمرير الكائن كـ this ولكن تمرير المعاملات كـ مصفوفة [Array].

func.apply(obj, [arg1, arg2]);
📍 .bind()

لا تستدعي الدالة؛ بل ترجع نسخة جديدة كلياً من الدالة مربوطة بسياق this المحدد للاستخدام لاحقاً.

const newFunc = func.bind(obj);

JavaScript ES6+ OOP & Classes Object-Oriented Design & Modules 
// تعريف الكلاس مع الوراثة الحديثة
export class Animal {
  constructor(name) {
    this.name = name;
  }
  makeSound() {
    return "صوت غير محدد";
  }
}

export class Dog extends Animal {
  constructor(name, breed) {
    super(name); // استدعاء الكونستركتور الأب
    this.breed = breed;
  }
  makeSound() {
    return "هو هو! 🐾";
  }
}

// في ملف آخر للاستخدام والاستيراد المنظم (ES6 Modules)
// import { Dog } from "./Animal.js";
const myPup = new Dog("ركس", "هاسكي");
console.log(myPup.makeSound()); // Output: "هو هو! 🐾"
