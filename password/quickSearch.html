تتبع الشيفرة البرمجية (C++)

تابع تظليل الأسطر أدناه لفهم كيفية حركة الكود البرمجي في الذاكرة أثناء عمل المحاكي على اليسار. 

int partition(vector<int>& arr, int low, int high) {
int pivot = arr[high]; // اختيار العنصر الأخير كمحور
int i = low - 1;
for (int j = low; j < high; j++) {
if (arr[j] <= pivot) {
i++;
swap(arr[i], arr[j]);
}
}
swap(arr[i + 1], arr[high]);
return i + 1;
}
void quickSort(vector<int>& arr, int low, int high) {
if (low < high) {
int pi = partition(arr, low, high);
quickSort(arr, low, pi - 1);
quickSort(arr, pi + 1, high);
}
}
الدالة النشطة حالياً: None
مؤشرات التقسيم: low=0, high=0

آلية عمل Quick Sort بالتفصيل

تتميز خوارزمية الترتيب السريع باعتمادها على أسلوب "فرق تسد" (Divide and Conquer)، حيث يتم تقسيم المشكلة الكبيرة (ترتيب مصفوفة كبيرة) إلى مشاكل أصغر فأصغر، ثم ترتيبها وحلها بشكل تعاودي (Recursive). وتتم العملية عبر 3 خطوات رئيسية:

1

أولاً: اختيار المحور (Pivot)

يتم اختيار عنصر مرجعي يسمى المحور (Pivot). يمكن اختيار هذا العنصر من البداية، أو النهاية، أو المنتصف، أو حتى اختيار عنصر عشوائي. في محاكينا هذا، اخترنا العنصر الأخير (Lomuto Partition Scheme).

2

ثانياً: التقسيم (Partitioning)

يعاد ترتيب المصفوفة بحيث تصبح جميع العناصر التي هي أصغر من المحور على يساره، والمسندة لليمين هي العناصر التي أكبر من المحور. في نهاية التقسيم، يوضع المحور في مكانه الصحيح والنهائي.

3

ثالثاً: الحل التعاودي (Recursion)

نطبق نفس العملية السابقة بشكل تعاودي ومستقل على الجزء الأيسر من المحور (القيم الصغرى)، وعلى الجزء الأيمن من المحور (القيم الكبرى) حتى يتم ترتيب المصفوفة كاملة بشكل متناسق.

كود C++ احترافي ومعياري مفسر بالكامل

هذا الكود متكامل وقابل للنسخ والتشغيل المباشر في أي مترجم (Compiler) مثل GCC أو MSVC. تم استخدام ناقل البيانات std::vector لضمان استقرارية ومرونة إدارة الذاكرة. 

#include <iostream>
#include <vector>
#include <utility> // For std::swap

// Function to partition the array based on a pivot (Lomuto Scheme)
int partition(std::vector<int>& arr, int low, int high) {
    int pivot = arr[high]; // Choosing the last element as pivot
    int i = low - 1;       // Index of smaller element

    for (int j = low; j < high; j++) {
        // If current element is smaller than or equal to pivot
        if (arr[j] <= pivot) {
            i++; 
            std::swap(arr[i], arr[j]);
        }
    }
    // Swap pivot into its correct sorted position
    std::swap(arr[i + 1], arr[high]);
    return i + 1;
}

// Main recursive Quick Sort function
void quickSort(std::vector<int>& arr, int low, int high) {
    if (low < high) {
        // pi is partitioning index, arr[pi] is now at correct place
        int pi = partition(arr, low, high);

        // Separately sort elements before partition and after partition
        quickSort(arr, low, pi - 1);  // Left side
        quickSort(arr, pi + 1, high); // Right side
    }
}

// Utility function to print the elements
void printArray(const std::vector<int>& arr) {
    for (int num : arr) {
        std::cout << num << " ";
    }
    std::cout << "\n";
}

int main() {
    std::vector<int> data = {10, 7, 8, 9, 1, 5};
    int n = data.size();

    std::cout << "Original array: ";
    printArray(data);

    quickSort(data, 0, n - 1);

    std::cout << "Sorted array: ";
    printArray(data);

    return 0;
}

تحليل الأداء الزمني والمساحة الإضافية

الحالة الفضلى O(n log n)

تقسيم مثالي ومتزن

تحدث عندما ينجح المحور في تقسيم المصفوفة إلى نصفين متساويين في كل خطوة تعاودية بالتساوي التام.

الحالة المتوسطة O(n log n)

الأداء الحقيقي والواقعي

هذه الحالة هي الأكثر تكراراً في التطبيقات البرمجية العملية، مما يجعلها أسرع من الترتيب بالدمج بفضل ثوابت خفيفة.

الحالة الأسوأ O(n²)

اختيار محور سيء للغاية

تحدث إذا كانت المصفوفة مرتبة بالكامل من قبل، وتم اختيار المحور كأكبر أو أصغر عنصر دائماً. (يمكن تجنبها بمحور عشوائي).

تعقيد المساحة الإضافية (Space Complexity): $O(\log n)$

تعتبر خوارزمية الترتيب السريع خوارزمية **في نفس الموقع (In-place Algorithm)** أي أنها لا تطلب مساحة مصفوفات خارجية إضافية، وتعود التكلفة البسيطة $O(\log n)$ لاستدعاءات مكدس الذاكرة التعاودية (Call Stack).

Simplified Quick Sort Summary

Quick Sort is a highly efficient, in-place sorting algorithm that uses the Divide and Conquer paradigm. It partitions an array into sub-arrays which are then sorted recursively.

1. Choose a Pivot

Pick a pivot element (like the first, last, or a random element in the array).

2. Partition

Reorder the array so smaller elements go left, and larger elements go right of the pivot.

3. Recursion

Apply steps 1 and 2 recursively to both left and right partitions.

Average Complexity: O(n log n)
Worst Complexity: O(n²)
Space Complexity: O(log n) [In-place]
