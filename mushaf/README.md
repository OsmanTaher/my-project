# ختمة

تطبيق ويب عربي لمتابعة حفظ ومراجعة صفحات القرآن الكريم، مع عرض مستوى الإنجاز حسب الصفحات والسور والأجزاء، وحفظ التقدم محليًا على جهاز المستخدم.

التطبيق يعمل كتطبيق ويب تقدمي **PWA** ويمكن تثبيته على الجهاز وتشغيله دون اتصال بالإنترنت بعد إتمام الإعداد الأول.

## المزايا

- متابعة صفحات المصحف كاملة وعددها 604 صفحة.
- تسجيل حالة كل صفحة:
  - لم تبدأ.
  - قيد الحفظ.
  - قيد المراجعة.
  - تم الحفظ والمراجعة.
- عرض نسبة الإنجاز والإحصائيات العامة.
- عرض السور الـ 114 مع رقم السورة ونوعها ومجال صفحاتها.
- عرض التقدم حسب الأجزاء الثلاثين.
- البحث عن السور بالاسم.
- تصفية السور حسب حالة الحفظ.
- تعيين حالة جميع صفحات السورة أو الجزء دفعة واحدة.
- اقتراح ورد يومي بمعدل صفحتين.
- حساب التاريخ المتوقع لختم المصحف.
- تسجيل النشاطات والإنجازات.
- حفظ التقدم تلقائيًا باستخدام `localStorage`.
- تثبيت التطبيق على الجهاز كتطبيق مستقل.
- العمل دون إنترنت بعد التخزين المؤقت للملفات والموارد.

## المتطلبات

- متصفح حديث مثل:
  - Google Chrome.
  - Microsoft Edge.
  - Firefox، مع اختلاف دعم التثبيت حسب النظام.
  - Safari على الأجهزة التي تدعم تطبيقات الويب التقدمية.
- خادم محلي لتشغيل المشروع.
- اتصال بالإنترنت عند أول تشغيل، لتحميل الموارد الخارجية وتثبيتها في التخزين المؤقت.

> لا تفتح `index.html` مباشرة من مستكشف الملفات باستخدام `file://`، لأن تحميل `suraHs.json` وتسجيل Service Worker يحتاجان إلى خادم محلي.

## التشغيل باستخدام VS Code

1. افتح مجلد المشروع في Visual Studio Code.
2. ثبّت إضافة **Live Server** إذا لم تكن مثبتة.
3. افتح الملف `index.html`.
4. اضغط بزر الفأرة الأيمن داخل الملف.
5. اختر **Open with Live Server**.
6. افتح الرابط الذي يظهر، مثل:

```text
http://127.0.0.1:5500/index.html
```

يمكن أيضًا تشغيل أي خادم HTTP محلي آخر من داخل مجلد المشروع، بشرط أن يخدم الملفات على `http://localhost` أو `http://127.0.0.1`.

## تثبيت التطبيق

1. افتح المشروع عبر الخادم المحلي.
2. انتظر حتى تظهر الصفحة وبيانات السور.
3. اضغط زر **تثبيت التطبيق** من الشريط العلوي.
4. وافق على نافذة التثبيت التي يعرضها المتصفح.
5. بعد التثبيت افتح التطبيق من قائمة التطبيقات أو الاختصار الذي أنشأه المتصفح.

قد يظهر خيار التثبيت أيضًا داخل قائمة المتصفح بدل الزر، خصوصًا إذا كان المتصفح لا يعرض زر التثبيت المخصص.

### ملاحظات مهمة عن زر التثبيت

- يظهر الزر للمستخدم الذي لم يثبت التطبيق بعد.
- يعتمد ظهور نافذة التثبيت على دعم المتصفح واستيفاء شروط PWA.
- يجب تشغيل المشروع عبر `localhost` أو `127.0.0.1` أثناء التطوير.
- عند استخدام نطاق حقيقي، يجب تشغيل الموقع عبر HTTPS.
- إذا كان التطبيق مثبتًا مسبقًا فلن يظهر زر التثبيت في وضع التطبيق المستقل.

## العمل دون إنترنت

يستخدم المشروع ملف `service-worker.js` لتخزين ملفات التطبيق وبيانات السور والموارد التي يتم تحميلها أثناء الاستخدام.

لضمان جاهزية التطبيق Offline:

1. شغّل المشروع مع وجود اتصال بالإنترنت.
2. افتح الصفحة وانتظر اكتمال تحميلها وظهور السور.
3. أعد تحميل الصفحة مرة أو مرتين حتى يتم تفعيل Service Worker.
4. ثبّت التطبيق من زر التثبيت.
5. أغلق الاتصال بالإنترنت وافتح التطبيق المثبت مرة أخرى.

يتم تخزين العناصر الأساسية التالية:

- `index.html`
- `script.js`
- `suraHs.json`
- `manifest.json`
- `logo.png`
- الموارد الخارجية التي يتم تحميلها أثناء أول زيارة مُدارة من Service Worker.

> عند تحديث ملفات المشروع، يجب زيادة قيمة `CACHE_NAME` داخل `service-worker.js`، مثل الانتقال من `mushaf-cache-v2` إلى `mushaf-cache-v3`، حتى يحصل المستخدم على النسخة الجديدة بدل النسخة القديمة المخزنة.

## بنية المشروع

```text
mushaf/
├── index.html          # واجهة التطبيق وهيكل الصفحة
├── script.js           # منطق التطبيق والتفاعل وحفظ التقدم
├── suraHs.json         # بيانات السور بصيغة JSON
├── manifest.json       # إعدادات التطبيق القابل للتثبيت PWA
├── service-worker.js   # التخزين المؤقت ودعم العمل دون إنترنت
├── logo.png            # شعار التطبيق وأيقونة التثبيت
└── README.md           # توثيق المشروع
```

## ملف بيانات السور

يحتوي `suraHs.json` على مصفوفة من 114 عنصرًا. كل سورة تحتوي على الخصائص التالية:

```json
{
  "id": 1,
  "name": "الفاتحة",
  "start": 1,
  "end": 1,
  "type": "مكية"
}
```

معنى الخصائص:

- `id`: رقم السورة.
- `name`: اسم السورة.
- `start`: أول صفحة مرتبطة بالسورة.
- `end`: آخر صفحة مرتبطة بالسورة.
- `type`: نوع السورة، مكية أو مدنية.

عند تعديل هذا الملف يجب الالتزام بصيغة JSON الصحيحة، خصوصًا:

- استخدام علامات الاقتباس حول أسماء الخصائص والقيم النصية.
- عدم إضافة فاصلة بعد آخر عنصر.
- عدم وضع `const SuraHs =` داخل الملف؛ الملف يجب أن يحتوي على JSON فقط.

## تخزين تقدم المستخدم

يُحفظ تقدم المستخدم محليًا في المتصفح باستخدام المفاتيح التالية:

- `quran_tracker_pages`: حالات الصفحات.
- `quran_tracker_streak`: عدد الأيام المتتالية.
- `quran_tracker_last_date`: تاريخ آخر نشاط.
- `quran_tracker_logs`: سجل الإنجازات والنشاطات.

لن تنتقل هذه البيانات تلقائيًا إلى جهاز أو متصفح آخر. حذف بيانات الموقع أو مسح Local Storage يؤدي إلى فقدان التقدم المحفوظ على ذلك الجهاز.

## التحديث والصيانة

بعد تعديل `index.html` أو `script.js` أو `suraHs.json`:

1. حدّث رقم `CACHE_NAME` في `service-worker.js`.
2. أعد تحميل الصفحة من الخادم المحلي.
3. افتح أدوات المطور وتأكد من عدم وجود أخطاء في Console.
4. تحقق من ظهور السور وعددها 114.
5. جرّب التطبيق بعد فصل الإنترنت.

بعد تعديل `logo.png`، تأكد من بقاء اسمه ومكانه كما هما، أو حدّث مسار الصورة داخل `index.html` و`manifest.json`.

## اختبار سريع

يمكن فحص الملفات الأساسية باستخدام Node.js:

```powershell
node --check .\script.js
node --check .\service-worker.js
Get-Content -Raw -Encoding UTF8 .\manifest.json | ConvertFrom-Json | Out-Null
Get-Content -Raw -Encoding UTF8 .\suraHs.json | ConvertFrom-Json | Out-Null
```

إذا لم تظهر رسالة خطأ، تكون الصياغة الأساسية للملفات سليمة.

## استكشاف الأخطاء

### لا تظهر السور

- تأكد من تشغيل المشروع عبر خادم محلي.
- افتح الرابط `http://127.0.0.1:5500/suraHs.json` وتأكد من ظهور JSON.
- أعد تحميل الصفحة.
- افحص Console بحثًا عن أخطاء JavaScript.

### زر التثبيت لا يظهر

- تأكد من استخدام Chrome أو Edge حديث.
- تأكد من تشغيل الصفحة عبر `localhost` أو `127.0.0.1` أو HTTPS.
- أعد تحميل الصفحة بعد تسجيل Service Worker.
- تحقق من أن التطبيق غير مثبت مسبقًا.
- افتح قائمة المتصفح وابحث عن خيار **تثبيت التطبيق**.

### التطبيق لا يعمل دون إنترنت

- افتح التطبيق مرة كاملة أثناء الاتصال بالإنترنت.
- أعد تحميل الصفحة بعد تسجيل Service Worker.
- تأكد من عدم وجود أخطاء في تبويب **Application > Service Workers**.
- عند تحديث المشروع، غيّر رقم `CACHE_NAME` ثم أعد التحميل.

### ما زالت نسخة قديمة تظهر

هذا يحدث بسبب التخزين المؤقت. غيّر رقم الإصدار في:

```javascript
const CACHE_NAME = "mushaf-cache-v3";
```

ثم أعد تحميل الصفحة. قد تحتاج إلى إعادة فتح التطبيق مرة أخرى.
